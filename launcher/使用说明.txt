财富经 · 本地网站启动器

使用方法
1. 双击项目根目录的「财富经一键启动.exe」。
2. 启动器会自动启动网站，准备就绪后自动打开默认浏览器。
3. 「停止服务」关闭网站服务；「启动网站」再次启动；「打开网站」重新打开网页。
4. 「一键更新网站」自动完成：停止网站 → 从 GitHub 拉取最新代码 → 依赖有变化时自动 npm install → 重新启动网站并刷新版本号。
5. 关闭启动器会自动停止它启动的网站进程及子进程。

一键更新
更新前会自动停止网站，更新成功后自动重启，无需手动操作。
窗口底部会显示当前版本（提交号 · 日期 · 提交说明），更新完成后自动刷新。
一键更新需要安装 Git for Windows（https://git-scm.com/download/win）并保持网络连接；未安装 Git 时按钮会提示原因并保持原版本。
更新失败会恢复更新前版本和本地源码修改，并自动重新启动网站，失败原因写在运行日志里。若自动恢复失败，会保留备份并停止服务，避免启动含冲突的代码。
如果 GitHub 上的文件和项目里未跟踪的本机文件重名（例如 package-lock.json），启动器会先把这些本机文件备份到 launcher\backup-<时间>，再重试更新。
更新只做快进合并。本地源码有未提交改动时，会先用 Git stash 备份修改及暂存区，更新后自动还原；备份保留，恢复说明位于 launcher\update-backups。未跟踪文件不会加入源码备份，仍按上一条处理同名阻挡文件。
本地修改与新版本有冲突或分支已分叉时，会恢复更新前版本及修改，并重新启动原网站。需要合并冲突的更新会在日志中说明，不会覆盖本地修复。

默认网址 http://localhost:3000。端口被占用时，会自动寻找 3001–3099 中的可用端口。
请以启动器窗口显示的网址为准。

需要 Windows 和 Node.js 22.12 或更新版本（建议 Node.js 24）。
启动器使用 Windows 自带的 .NET Framework，无需额外安装 GUI 框架。
缺少项目依赖时会自动运行 npm install，首次安装需要网络连接。
启动器必须与 package.json、server.ts 位于同一目录，launcher 文件夹也需保留。
网站地址 localhost 的浏览器数据按端口分别保存，通常固定使用 3000 即可。

没有配置 Gemini API Key 时，网站使用原有的本地规则功能。
如需启用 AI 功能，请在项目根目录的 .env 中设置 GEMINI_API_KEY，然后重启网站。
启动器不保存、不显示密钥，也不修改已有 .env。

故障排查
窗口会显示运行日志；完整日志位于 launcher\launcher.log。
如果缺少 Node.js 或 Git，按提示安装后重新打开启动器即可。
自检：在项目目录运行 .\财富经一键启动.exe --self-test。
自检不会打开浏览器，会验证网页响应、端口避让、停止、重新启动和一键更新，完成后自动退出。
结果写入 launcher\self-test.txt；GUI 预览写入 launcher\preview.png。
修改源码后可运行：powershell -NoProfile -ExecutionPolicy Bypass -File launcher\build.ps1。

图标
money.png 为通过内置 imagegen 工具生成的透明背景金元宝与金币 PNG。
money.ico 为 Windows 应用图标格式，已嵌入 EXE，原始 PNG 保留在 launcher 文件夹。
当前图像生成接口没有模型选择参数，无法指定或验证「image2.5」模型标识。
